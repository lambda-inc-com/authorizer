# 🤖 多智能体工作流生成系统 - 交互式测试器

## 📋 功能介绍

这是一个交互式测试工具，允许您输入自定义需求来测试多智能体工作流生成系统。系统会自动分析您的需求并生成相应的工作流配置。

## 🚀 快速开始

### 1. 运行测试器
```bash
cd ai-core
python test_workflow_interactive.py
```

### 2. 输入需求
启动后，直接输入您的工作流需求描述，例如：
```
🎯 请输入您的工作流需求: 创建一个用户注册工作流，包含邮箱验证和数据库存储
```

### 3. 查看结果
系统会显示生成的工作流信息，包括：
- 工作流名称和描述
- 节点列表和类型
- 详细的JSON配置（可选）

## 📋 支持的节点类型

系统支持以下类型的工作流节点：

### 基础节点
- **workflowStart**: 工作流开始节点
- **workflowEnd**: 工作流结束节点

### 数据库操作节点
- **dbQuery**: 数据库查询节点
- **dbCreate**: 数据库创建节点
- **dbUpdate**: 数据库更新节点
- **dbDelete**: 数据库删除节点

### 外部服务节点
- **http**: HTTP请求节点
- **llm**: LLM对话节点

### 逻辑控制节点
- **condition**: 条件判断节点
- **code**: 代码执行节点
- **transaction**: 数据库事务节点

## 🎯 测试流程

1. **需求分析**: 需求分析智能体解析您的自然语言需求
2. **工作流组合**: 工作流组合智能体生成完整的工作流配置
3. **验证检查**: 工作流验证智能体检查配置的正确性
4. **结果展示**: 显示生成的工作流信息和配置

## 🛠️ 故障排除

### 常见问题

1. **导入错误**: 确保您在 `ai-core` 目录下运行测试
2. **依赖缺失**: 确保安装了所有必要的Python包
3. **需求不明确**: 尝试使用更具体的需求描述

### 调试技巧

1. 使用 `status` 命令检查系统状态
2. 使用 `history` 命令查看之前的测试结果
3. 从简单的需求开始，逐步增加复杂度
